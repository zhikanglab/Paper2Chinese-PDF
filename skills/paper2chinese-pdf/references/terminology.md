# SHPB and porous cementitious research: translation glossary

| English | Preferred Chinese | Notes |
|---|---|---|
| split Hopkinson pressure bar (SHPB) | 分离式霍普金森压杆（SHPB） | Use source's actual configuration. |
| viscoelastic SHPB | 黏弹性SHPB | PMMA rods require wave dispersion and attenuation consideration. |
| PMMA (polymethyl methacrylate) | 聚甲基丙烯酸甲酯（PMMA、有机玻璃） | A precision bar is not arbitrary acrylic sheet. |
| incident/reflected/transmitted wave | 入射波/反射波/透射波 | εI/εR/εT maintained. |
| incident / transmitted bar | 入射杆 / 透射杆 | Not projectile / striker. |
| striker | 撞击杆（弹丸） | Distinguish pneumatic pressure. |
| pulse shaping | 脉冲整形 | e.g., copper or rubber shapers. |
| stress equilibrium | 动态应力平衡 | Validate ends versus time. |
| strain rate | 应变率 | s⁻¹, not firing pressure or striker speed. |
| peak stress | 峰值应力 | Not peak force. |
| dynamic increase factor (DIF) | 动态增强系数（DIF） | Dynamic peak / appropriate static strength. |
| energy absorption ratio/efficiency (EAR) | 能量吸收率/吸能效率（EAR） | Usually Wabs/Wi, confirm source. |
| specific energy absorption (SEA) | 比吸能（SEA） | Per mass, check author definition. |
| absorbed energy density | 单位体积吸收能量 | Wabs/V, not Wabs/m. |
| dynamic modulus | 动态弹性模量 | Different measurement methods possible. |
| cell wall | 孔壁 | Not particle interface. |
| pore coalescence | 气泡/孔洞合并 | Depends fresh vs hardened stage. |
| porosity | 孔隙率 | Not number density. |
| pore size distribution | 孔径分布 | Distinguish equivalent diameter. |
| pore number density | 孔数密度 | Count/area or volume. |
| CT / X-CT | X射线计算机断层扫描（CT） | Imaging scales matter. |
| fragmentation fractal dimension | 破碎分形维数 | Explain fitted definition, do not assume geometric bound applies. |
| fly ash (FA) | 粉煤灰（FA） | **FA can mean foaming agent** in other articles; check each. |
| calcium stearate (CS) | 硬脂酸钙（CS） | Stabilizer. |
| NaHCO₃ | 碳酸氢钠 | Not CaCO₃. |
| magnesium phosphate cement (MPC) | 磷酸镁水泥（MPC） | Specific chemistry must be preserved. |
| dry density | 干密度 | Distinguish tested condition. |
| apparent density | 表观密度 | State conditioning. |
| axial prestress | 轴向预应力/预压应力 | Static-dynamic combined loading. |
