# Final release checklist — verify all checks explicitly

**Source fidelity**
- [ ] Exact original English title appears immediately below Chinese title.
- [ ] Authors, journal, year, DOI independently checked against supplied source.
- [ ] All original sections and subsections represented in complete translated text.
- [ ] Every quantitative claim and apparatus condition correctly translated.
- [ ] Multi-column text reading order verified visually, not sorted blindly by PDF coordinates.
- [ ] Source figures and their panels reconciled one-by-one with translated positions.
- [ ] Source tables: row/column totals, units, legends, footnotes and negative signs checked.
- [ ] Numbered formulas: original signs, superscripts, subscripts, and equation numbers checked.
- [ ] Source appendix labels, images, formulas and discussions have their own translated locations.
- [ ] Reference entries match the original list; in-text reference markers retained.
- [ ] Original ambiguities are retained with translator notes, not silently fixed.

**Reader-first page-flow**
- [ ] All figures placed in corresponding text region, not bundled at end.
- [ ] All tables placed in corresponding text region, not bundled at end.
- [ ] All formulas adjacent to their discussions, not bundled at end.
- [ ] No empty figure boxes; all source crops have correct aspect ratio and all axes/legends/panels.
- [ ] Body line-height, margins, font sizes and section hierarchy match sample editions.
- [ ] Chinese title and original English title visually distinguishable and readable.
- [ ] Figures, tables and captions readable at ordinary 100% zoom.

**Rendering and archived-file hygiene**
- [ ] Every PDF page rendered, contact-sheet checked, complex pages examined in full.
- [ ] No missing fonts, tofu glyphs, overlap, clipped equations, missing margins, orphan headings or blank filler pages.
- [ ] Some dense numerical tables cross-checked directly with original image.
- [ ] Source PDF unchanged; approved Chinese PDF numbered identically to original.
- [ ] Only requested accepted formats in user-specified folder(s); DOCX must never be inserted in a PDF-only folder. No intermediate renders/rejected versions in Library.
- [ ] Claim only checks actually performed. Semantic translation fidelity is never proven by an automated filename/figure-count audit alone.


**Word / dual-format release gate (when requested)**
- [ ] Native editable `.docx` is generated from the SAME verified translated manuscript as PDF, rather than screenshotting the entire PDF.
- [ ] Chinese title directly above the exact English original title in the Word file.
- [ ] All source figures/tables/equations appear at their text anchor; image count audited in the `.docx` package.
- [ ] No body paragraphs set to justify/distribute, no abnormal width or CJK gaps.
- [ ] Subscript and superscript verified as actual Word character properties or correct Word equation objects, not literal underscores.
- [ ] Word `.docx` rendered to page images, every page visually inspected and corrected (NOT inferred from PDF screenshots).
- [ ] If both outputs requested, numerical claims and section/asset ordering consistent between `.pdf` and `.docx`, with reflow differences allowed.
- [ ] Confirm explicit output preference; keep research archive PDF-only if that is its standing rule.
