# Paper2Chinese PDF / Word — high-fidelity academic translation workflow

This is an **Agent Skill plus a local Python layout/QA toolkit** for producing source-aligned Simplified Chinese translations of English research-paper PDFs. It supports **PDF (default), editable Word DOCX, or both**.

**Status:** early public starter. This is **not** a fully automated translation service. A human or capable AI agent must translate and review the entire paper and prepare the ordered JSON manifest with source-page figure/table/equation crop coordinates. The software can inspect the English PDF, typeset approved Chinese content, and run limited automated structural QA. It does **not** certify semantic fidelity or guarantee arbitrary PDFs can be translated without proofreading.

## What makes it different

- Original English title stays immediately beneath the Chinese title.
- Every original figure, table and equation is placed **inline near the translated passage discussing it**, never dumped into a rear English appendix.
- The translator must preserve paragraph order and a private source-page/paragraph alignment log so readers can verify translations side by side.
- Body text uses natural left alignment, avoiding stretched CJK/Latin character spacing.
- Scientific indices use real subscript/superscript formatting (e.g. W with I subscript), rather than underscores.
- PDF and Word files are generated from the same reviewed manuscript; **each format must be independently rendered and visually inspected**.

## Getting started

```bash
pip install -e '.[test]'
python examples/make_synthetic_source.py
paper2zh inspect examples/synthetic_source.pdf --out work/source.json --preview work/previews
paper2zh build examples/example_manifest.json --format pdf --out work/translation.pdf
paper2zh build examples/example_manifest.json --format docx --out work/translation.docx
paper2zh build examples/example_manifest.json --format both --out work/translation
paper2zh audit examples/example_manifest.json work/translation.pdf
paper2zh audit examples/example_manifest.json work/translation.docx
pytest -q
```

The sample source generated by `make_synthetic_source.py` is **fictional, not a copyrighted journal article**. A real translated paper requires complete reviewed Chinese text and carefully inspected crop locations. See `README.md`, `skills/paper2chinese-pdf/SKILL.md` and `PROMPT_另一个聊天框直接使用.md` for full Chinese workflow instructions.

## Integration

- Codex/repository Agent Skills: `.agents/skills/paper2chinese-pdf/`
- Portable skill package: `skills/paper2chinese-pdf/`
- Agent Plugin starter manifest: `plugin.json`
- ChatGPT chats/projects: paste `PROMPT_另一个聊天框直接使用.md` and supply a reference original/approved translation pair.

A GitHub repository or plugin manifest does **not** mean the project is already installed, published, approved, or hosted in the ChatGPT Plugin Directory. The skill invokes available file-processing tools; there is currently no hosted MCP backend.

## Safety, copyright and privacy

Do not commit third-party journal PDFs, translated full texts, user data, API secrets or proprietary font files to public GitHub. The repository contains MIT-licensed original code and synthetic examples only. Review publisher licensing before redistributing translated figures or papers.
